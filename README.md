# data-science-portfolio

Source for my data science portfolio, published with GitHub Pages:

**Live site:** https://yudan-huang.github.io/data-science-portfolio/

## What is here

| File | Purpose |
| --- | --- |
| `index.md` | The portfolio page itself: introduction, skills, project showcase |
| `_config.yml` | GitHub Pages / Jekyll configuration |
| `images/` | Figures used on the page |

## How it is published

The site is built by GitHub Pages from the `main` branch, root folder (`/`), using
Jekyll. `index.md` is the entry file: Jekyll renders it to `index.html` at the site root.

To update the site, edit `index.md`, commit, and push to `main`. Pages rebuilds
automatically within a minute or two.
